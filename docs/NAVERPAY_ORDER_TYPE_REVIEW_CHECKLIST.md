## 현재 위치 (가입 프로세스, p.3)
```
가입신청서+서류 → 심사(3영업일) → [1차 가입 승인 = 인증키 발송] ← 우리 여기 통과
  → 시스템연동 ← 지금 이 단계 (기술 연동)
  → 최종 승인/가입 완료 → 심사(3~5영업일, AML 고객확인) → 서비스 시작(정산)
```
인증키 4개 받음 = 1차 승인 완료. **시스템연동 끝내고 "심사요청" 하면 최종심사 진입.**

## 🔴 푸르픽 최종심사 걸림돌 (반드시 선조치)

### 1. 현금결제 유도 문구 금지 (p.11, 유의사항 11)
- "무통장입금 확인", 현금결제 유도 문구 → **여신전문금융업법 위반, 심사 보류**
- 현금결제 할인 제공 불가. 무통장입금 금액 = 카드/네이버페이 금액 **동일**해야.
- **푸르픽 현황**: 무통장입금이 현재 주력 → 안내 문구·페이지 점검 필요.
  - 조치: "무통장입금" 문구는 결제수단 명칭으로만 OK. "무통장 시 할인" 류 금지.

### 2. 쇼핑몰 하단 푸터 8개 필수정보 (p.35, 유의사항 10)
누락 시 심사 보류. 필수 8종:
① 회사소개 ② 이용약관 ③ 개인정보처리방침 ④ 사업자정보확인(공정위 링크)
⑤ 상호/대표자 ⑥ 사업자등록번호 ⑦ 통신판매업신고번호 ⑧ 주소/전화/이메일/입금계좌
- 이용약관 = 공정위 표준약관 사용해야
- 사업자정보확인 = 공정위 사업자정보확인 페이지로 링크 연결
- **조치**: 푸르픽 Footer 점검 → 8종 다 있는지.

### 3. 통신판매업 신고 + 공정위 조회 (p.4, 가입조건 3·4)
- 가입 전 통신판매업 신고 완료 + 공정위 정상 조회 필수
- 쇼핑몰 하단 정보 ↔ 사업자등록증(1년내) ↔ 공정위 정보 **3자 일치**
- **조치**: 통신판매업 신고번호 확보 + 푸터 반영.

## 🟡 통신판매 중개사이트 필수 기재 (p.36, 유의사항 12) — 구매대행이면
- 통판중개 사이트면: ①중개 고지 ②판매자 연락처 ③입점판매자 필수정보(사업자7기/개인3기)
- **푸르픽은 자체 PB 판매(중개 아님)** → 해당 없음. 단 소싱상품이면 판매자=푸르픽 자기.

## 🟢 푸르픽 무관/통과 항목
- 등록불가 URL(p.25): coupang/kakao/스마트스토어/블로그 등 → 푸르픽 www.purrpik.co.kr 자사몰 = OK
- 신용카드 제한상품(p.8): 유가증권/상품권만 → 셸터/쿨매트 무관
- 해외배송 불가(p.32): 우리 국내배송 = 무관
- 도서산간 추가배송비(p.31): 전상품 무료배송 = 무관
- 개인통관고유부호(p.34): 구매대행/해외직배 아님 = 무관
- 도서정가제(p.37): 도서 안 팜 = 무관

## ⚠️ 소싱상품 주의 (p.9, 해외구매대행 취급제한)
셸터/쿨매트가 **중국 소싱 구매대행 형태**로 심사되면:
- 전기용품(어린이용품 포함): KC 안전인증 없으면 판매불가 → 셸터/쿨매트는 전기용품 아님, OK
- 식품/화장품/의료기기/의약품: 구매대행 판매 제한 → 우리 해당 없음
- **포지셔닝: 푸르픽 자체 브랜드(PB)로 명확히** = 구매대행 심사 회피
